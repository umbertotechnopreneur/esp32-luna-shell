# Authored demos

Authored animation bindings for immutable generated data. These are not
alternate sensor or service owners. Synthetic input belongs only in the Windows
simulator, never in a firmware snapshot.

Resources: `assets/cody/runtime` and `assets/cody/rig`.
See [runtime](../../../../../docs/cody/runtime.md).
