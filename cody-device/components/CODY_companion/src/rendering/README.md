# Rendering

Pearl-jelly compositing, damage bounds and dirty-tile planning. Operates on
caller-owned surfaces and prepared geometry; does not own sensor acquisition,
scene routing or display transactions.

Generated pearl assets stay under `assets/cody/appearance/jelly-scanline`.
See [rendering and memory ownership](../../../../../docs/cody/runtime.md#experiments-and-source).
