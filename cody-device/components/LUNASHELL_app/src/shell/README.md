# Minimal application shell

The single visual application admitted by the `ui-minimal` build profile. Its
existing CMake entrypoint remains `LUNASHELL_app_shell.cmake` at component root.

The shell package stays in `package_shell/`; full-app documents and lifecycle sources
are not admitted by this profile.
