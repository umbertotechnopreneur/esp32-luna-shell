# Pairing presentation

Application-side pairing presentation/actions and QR rendering. Shared app metadata
is private to `../runtime/`; public declarations stay in `include/`.

The platform network services own Wi-Fi/Bluetooth/provisioning lifecycle, not this
presentation layer.
