# Native application runtime

Brookesia application lifecycle, canonical snapshot binding, alert service and log
view behavior. `LUNASHELL_app_internal.hpp` is private shared application metadata.

Public app contracts stay in `include/`. Declarative GUI source and staged package
content remain in the component's `gui/` and `package/` trees.
