# Scenes

Generic cloud/title/content composition, typed text, onboarding routes,
appearance controls and the nonblocking typewriter-audio bridge. Backend results,
not rendering progress, decide pairing outcomes. Borrowed frame content must
remain immutable until retirement.

Authoring: `assets/cody/scenes/scenes.json`. Contracts:
[runtime](../../../../docs/architecture/cody/runtime.md) and
[onboarding](../../../../docs/architecture/cody/onboarding.md).
