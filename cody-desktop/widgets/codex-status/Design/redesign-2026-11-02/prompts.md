## 01 / Fluent Pearl

### Generation prompt

Front-facing flat UI screenshot, crisp readable typography, no perspective, no device photography. Neutral presentation backdrop, restrained shadows. This is an OpenAI Usage native desktop app, implementable in WinUI 3 and GTK, NOT a website.
Functional content consistent across proposals: title "OpenAI Usage", small original clock app icon, unboxed icon-only controls for pin, settings, about, compact mode plus appropriate window controls. A compact horizontal summary aligned with the countdown: "Weekly limit" / "22%", "Today tokens" / "109.66 M", "Remaining credits" / "59,602.72". Make percentage the primary metric; use monospaced numeric typography. Design constraints: single continuous app surface, NO dashboard cards, NO pill cards around statistics, no decorative borders around groups, no rainbow haze, no giant padding, no low-contrast text, no scrolling/clipping/cropped controls. Board caption: "01 / Fluent Pearl".
Style: polished Windows 11 Fluent light acrylic, softly frosted pearl-white continuous surface with only the faintest cool blue translucency. Ink-to-deep-teal subtle text gradients on key numbers, dark slate labels. Segoe-like humanist headings and refined monospace values. Very shallow native titlebar. Clock matte charcoal tiles with warm white digits, slim realistic center seam, elegant reduced proportions. Horizontal, calm, precise native productivity widget. Thin teal active-tab underline, soft small corner radii. Generous but efficient spacing. This should feel like a beautifully resolved native Windows utility.
