# Home token proposals - 2026-10-14

These are illustrative ImageGen concepts for the native circular Home screen.
They use the existing pearl-cloud character as a reference and synthetic token
values. They are not firmware screenshots or physical-display evidence.
The user selected proposal 02 for native implementation on 2026-10-14, then
requested three lower Home panels and a continuous command marquee.

| Proposal | Intended treatment |
| --- | --- |
| [01 - Compact card](01-compact-card.png) | Unselected alternative: Free capsule, context bar and secondary Window/timer row. |
| [02 - Context arc](02-context-arc.png) | Selected: large Free value, circular availability accent and secondary Last/Window values. |
| [03 - Dual metrics](03-dual-metrics.png) | Two equal Free/Window tiles with a secondary timer. |

Generated with the built-in ImageGen tool. Each image is retained byte for byte
from its generated output. [prompts.json](prompts.json) contains the full prompt
set and the native-reference path. No CLI/API fallback was used.

The token numbers are illustrative: Last 155,173, Window 475,000 and Free
319,827 become Last 155K TT, Window 475K TT and Free 319K TT. `K` uses decimal
thousands truncated for the compact Home. Canonical and protocol counters retain
full precision. Context graphics represent the same coherent source
pair; they must not suggest cumulative spending or a guaranteed next-turn budget.

The implementation retains the cloud, activity title and model above three
lower panels: Tokens with IMU and timer; Model with price and thinking effort;
Session with connectivity, chat ID and device IP. A passive tap changes only
the lower panel. The Available commands heading and old full-screen pages are
removed; supported commands scroll right to left at the bottom.

Native font metrics, local circular chords and damage revisions govern the
actual layout. Compaction stays orange and indeterminate, with its original
event/sound ownership. The PNG is a design reference, not a playback asset.
Validation and installation evidence belong to [done.md](../../../../done.md).
