# Home context arc

The approved concept places Free at the center of the token panel, with Last
and Window as secondary values. The image uses illustrative data.
[Design reference](02-context-arc.png) · [Image prompt](prompts.json)

The token numbers are illustrative: Last 155,173, Window 475,000 and Free
319,827 become Last 155K TT, Window 475K TT and Free 319K TT. `K` uses decimal
thousands truncated for the compact Home. Canonical and protocol counters retain
full precision. Context graphics represent the same coherent source
pair; they must not suggest cumulative spending or a guaranteed next-turn budget.

The native implementation draws the arc from current context occupancy. Its
geometry, colors and placement are specified in the [Home layout](../../layout.md#companion-panels-status-and-debug).
