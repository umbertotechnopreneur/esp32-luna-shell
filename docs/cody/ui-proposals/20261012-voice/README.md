# Voice screen proposals

Ten historical synthetic design studies, not device captures. Project/model/branch/cost captions are illustrative and never enter firmware snapshots. The model price is a catalog cost band, not dollars or a measured session bill.

The later 2026-10-12 recording-screen implementation supersedes these studies'
sixteen immutable poses and alternating lower hint. Current source uses filled
procedural alpha layers, fresh canonical microphone gain and persistent send,
silence and discard instructions. The public `cody-voice-ui` check produces a
visibly SIMULATED preview from the actual native ribbon and font code under
`artifacts/checks/cody-voice-ui/`; it does not prove device timing or touch behavior.
See [runtime.md](../../runtime.md#one-way-voice-input-source-increment) for the current contract.
