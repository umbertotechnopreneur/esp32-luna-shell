# Voice screen proposals

These ten synthetic studies explore the recording screen. Their project,
model, branch and cost captions use illustrative data. Model price indicates
a catalog cost band.

The native screen animates a ribbon from measured microphone gain and keeps
the send, silence and discard instructions visible. The `cody-voice-ui` check
can produce a SIMULATED preview under `artifacts/checks/cody-voice-ui/`.
Timing and touch behavior require device verification. See the
[recording contract](../../runtime.md#one-way-voice-input-source-increment).
